LogiDisplaySwitch (Windows 无感后台联动工具)
==================================================

【核心功能】
配合 Mac 端程序，实现罗技 MX Keys 键盘与 MX Master 3 鼠标全自动双向切换：
1. 在 Mac 键盘按 2 -> 鼠标与显示器自动切到 Windows (DP 16)；
2. 在 Win 键盘按 1 -> 鼠标与显示器自动切回 Mac (Type-C 27)！
全程无需手动按鼠标底部切换按键！

【使用方法（仅需操作一次）】
1. 将本 windows 文件夹拷入 Windows 电脑的任意位置（如 D:\LogiDisplaySwitch 或 C:\Tools）；
2. 双击运行【一键安装后台自启(无弹窗).bat】；
3. 完成！脚本已立即在后台静默运行，且开机自动无感自启，没有任何黑框弹窗或图标打扰。

【测试与维护】
- 如果想测试鼠标能否成功切回 Mac，可直接双击【立即切回Mac(测试).bat】；
- 如果以后不需要该功能，双击【一键停止并卸载.bat】即可一秒清除自启与进程。
